v2Italia

This repository is a Next.js + Prisma application (server-side features like API routes, auth, DB, Stripe/PayPal). GitHub Pages serves only static files, so this page is a minimal entrypoint living in docs/.

If you want the full app reachable on the internet, deploy it to a platform that supports Node.js + a database (e.g. Vercel/Render/Fly) and keep GitHub Pages only for docs/landing.

Local Run

Typical dev commands (requires your environment variables, DB, etc.):

npm install
npm run prisma:generate
npm run prisma:migrate
npm run prisma:seed
npm run dev
